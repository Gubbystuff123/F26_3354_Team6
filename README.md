# Waitlist Test

This is a java project demonstrating a waitlist position management system and it's junit tests.

# Requirements

- Java JDK 17 or higher
- IntelliJ IDEA or another similar IDE
- JUnit to run the tests

# Install Dependencies

1. Open the project in IntelliJ IDEA.
2. Go to File -> Project Structure -> Projects
3. Select appropriate JDK version
4. Add JUnit if Intellij notifies that it is missing

# Configure Environment Variables

no environmental variables were used. You just select hte project in Intellij 
and JUnit is configured as its project dependency.

# How to Run the Project Locally

1. open 'src/WaitlistManagement.java" in IntelliJIDEA
2. use the "run" option for the project or main class.

# How to Run the Tests Locally

1. open 'Test/WaitlistManagementTest.java" in IntelliJIDEA
2. use the "run" option by clicking the green button or right clicking.
3. make sure / confirm that the tests pass in IntelliJ's test result window.
